今天的挑戰

  • 1多套 ERP 系統加上大量試算表，缺乏統一的業務視圖。
  • 2人工彙整與重覆輸入，讓報表產出緩慢且容易出錯。

把文件與螢幕畫面變成乾淨資料。From documents and screens to clean data.

  • 排程批次同步：讓倉儲資料保持最新，無需人工觸發。
  • 工作流程編排：串起擷取、刷新與報表。

保安與治理

天生值得信賴。Trustworthy by design.

🔐

加密憑證

資料庫與 API 密碼以 AES-256-GCM 密文儲存，絕不離開伺服器；清單僅顯示「已設定密碼」。

📜

完整操作記錄

登入、刷新、整合、匯出與管理異動都會記錄，附逐步追蹤與 IP／裝置資訊。

👤

角色權限

逐使用者模組權限加上逐報表分享，皆於伺服器端強制；暫停的帳號會被封鎖。

📖

唯讀且白名單化

自訂資料集 SQL 僅限單一唯讀 SELECT；報表識別碼依真實欄位白名單驗證。

🖥️

環境登錄

伺服器／資料庫設定檔密碼遮罩並附連線測試，正式與測試環境分明。

⚙️

可部署服務

以受管理的背景服務執行；前端可熱更新，後端可乾淨重啟。
